
# ⚽ FOOTBALL LEGENDS 3D

Un jeu de football 3D sur Android.

## Fonctionnalités prévues
- Matchs de football
- Mode Carrière
- Multijoueur en ligne
- Joueurs en 3D
- Stades détaillés
- Commandes tactiles
- Commentaires et effets sonores

## Technologie

- C#
- Blender
- Android
